01 • SOBRE MIM

Mais do que tecnologia.

Eu gosto de criar.

Atualmente curso Sistemas de Informação e estou no começo da minha trajetória na área de tecnologia. Ainda tenho muito para aprender, mas gosto de enxergar esse momento como uma oportunidade para experimentar, descobrir meus interesses e entender que tipo de profissional quero me tornar.

Meus primeiros projetos surgiram justamente desse processo, cada um deles me ensinou alguma coisa diferente: programação, organização, resolução de problemas, criatividade e, principalmente, a importância de não ter medo de começar mesmo quando eu ainda não sei fazer tudo. Ao mesmo tempo, percebi que criar não acontece somente através da programação, algumas das experiências mais importantes que construí aconteceram em equipe, na organização de eventos, na criação de ideias e em momentos em que precisei sair da minha zona de conforto.

Por isso, este portfólio reúne diferentes partes de quem eu sou: os projetos que estou desenvolvendo na tecnologia e as experiências que me ensinaram a criar, organizar, colaborar e transformar ideias em algo real.

UMA COISA SOBRE MIM

Por muito tempo, a timidez fez parte da forma como eu me enxergava, eu tinha dificuldade para falar em público, me expor e simplesmente ocupar meu espaço, e com o tempo, comecei a perceber que sair da minha zona de conforto não era tão assustador quanto parecia. Hoje, cada vez que aceito um desafio novo, percebo um pouco mais da pessoa que estou me tornando.

02 • PROJETOS

Coisas que eu criei.

Alguns dos projetos que fazem parte do meu aprendizado em programação e tecnologia.

01 JOGO

Escape Room

O protótipo de um jogo simples de enigmas em que o jogador precisa resolver desafios para conseguir escapar de diferentes salas. O projeto foi uma forma de transformar conceitos básicos de programação em uma experiência interativa, trabalhando com variáveis, entradas de dados, condicionais, loops, funções, listas e controle de pontuação.

Python HTML CSS
Ver projeto GitHub
02 SISTEMA

PetCare

O protótipo de um sistema para organização de um pet shop, reunindo animais, donos, consultas, serviços, vacinas e histórico. A ideia foi transformar uma situação do cotidiano em um projeto de programação, praticando a organização de dados e a criação de funcionalidades para resolver um problema de forma estruturada. Obs: a ideia surgiu após uma experiência pessoal aos resgatar um gato e levá-lo ao veterinário.

Python HTML CSS
Ver projeto GitHub
03 ORGANIZAÇÃO

GroupTask

O protótipo de um sistema pensado para facilitar a organização e a divisão de tarefas em trabalhos em grupo, com o objetivo de tornar o processo mais eficiente e colaborativo. A proposta surgiu de uma situação bastante comum entre estudantes: dividir tarefas, acompanhar responsabilidades e entender o que cada integrante precisa fazer. O projeto me permitiu trabalhar principalmente com Java e pensar em como a tecnologia pode ser utilizada para tornar uma tarefa cotidiana mais organizada.

Java HTML CSS
